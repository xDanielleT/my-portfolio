Job Fit Analyzer

I paste in a job posting. An AI compares it to the skills I can actually back up, scores the fit, and tells me what matches, what is missing, and what to watch out for.

  • n8n
  • Claude API
  • Google Sheets
  • Gmail
  • JavaScript

COVER

PAGE 1The problem

Job hunting means reading a lot of postings and guessing which ones fit.

I wanted a faster first pass. The catch with AI is that it will happily tell you that you are qualified for everything.

So the real job was not "score this posting." It was "score it using only what I can prove."

That one rule shaped the whole build: what goes in the prompt, how the reply is checked, and what happens when it goes wrong.

1

PAGE 2How it works

  1. Form. I paste a job title, company, link and description.
  2. Claude API. The posting goes to Claude with a prompt listing my confirmed skills, the skills I am still learning (counted as gaps), a scoring rubric, and what counts as a red flag.
  3. Check. A short JavaScript step confirms the reply is valid and complete.
  4. Results. A row is added to a Google Sheet and I get a plain-text summary email.
  5. If it breaks. I get an alert email with the raw reply, and nothing is written to the Sheet.

PAGE 5What I tested

I ran it on real Indeed postings, including a junior web developer role and an Android engineering role.

The Android role scored 15/100. That is the right answer: I have no confirmed Android experience.

I also broke the reply on purpose to confirm the alert email arrives and the Sheet stays clean.

A tool that only works when nothing goes wrong is a demo. I wanted to see the failure path work too.

5

PAGE 6What I learned

  • Tell the model what it may not claim. A confirmed-skills list plus a "not confident yet" list kept results honest. Gaps showed up as gaps.
  • Treat the posting as untrusted text. The prompt tells Claude to ignore any instructions written inside the job description.
  • Validate AI output before using it. My first version broke when a reply was cut off, and later when it started with a different kind of block. Reading the right part and checking it fixed both.
6
  • A rubric calms the scores. Before it, the same posting could score noticeably differently between runs. After, the swings got smaller but did not vanish, so I treat the score as a rough guide.
  • Plan for failure. The error path took as long to build as the happy path. It is the part I would trust most if I left this running.

LIMITS AND NEXTWhat it can't do yet

It only knows the skills in its prompt, so that list has to stay current. It runs on demand while n8n is running, not around the clock.

Next: run the same posting several times to measure consistency, and add a step that drafts a tailored resume for me to approve before anything is sent.
